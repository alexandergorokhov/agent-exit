- **Real node:** the `tests/sandbox` tests (key list before and after a buy, the old keys failing with the node's own error, a failed key batch refunding the buyer) passed on a local NEAR node at commits `609b135` and `63d597c` (not yet re-run green on the current code; `make test-sandbox`). ## Code hash in 3 commands

The testnet world (`agentexit6.testnet`) runs code hash `3XqAPt3krfpJG9UWFHnZVyDYSws4ZnN4H3B27hCXPuuw`, exactly the reproducible build committed in `contracts/res` (sha256 `259d414a75fb83010140fa27cdc29e20cce79b4674600860ff2e5813a25e827e`, 641,891 bytes). Source: commit `1dc6ca1` (the contract sources are unchanged since), built with `make build` in `sourcescan/cargo-near:0.22.0-rust-1.97.0` with the testnet accounts compiled in; the build's own NEP-330 metadata records that commit.

```sh
# 1. Prints the sha256 above (`make build` on a clean checkout rebuilds the same bytes)
sha256sum contracts/res/agent_exit.wasm
# 2. The deployed account (read-only, public RPC): result.code_hash is the base58 above
curl -s https://rpc.testnet.near.org -H 'Content-Type: application/json' -d '{"jsonrpc":"2.0","id":1,"method":"query","params":{"request_type":"view_account","finality":"final","account_id":"translator.factory.agentexit6.testnet"}}'
# 3. NEP-330 build metadata stored in the contract: build image and source
near contract call-function as-read-only translator.factory.agentexit6.testnet contract_source_metadata json-args '{}' network-config testnet now
```

`make judge` runs check K0 on the files: the hash of the committed `contracts/res/agent_exit.wasm` (`3XqAPt3k…`, the hash the testnet world runs) must equal `web/data/testnet.json`, `out/testnet/deploy.json`, `.mcp.json` and `SHA256SUMS`. It prints commands 2 and 3.

## Verify testnet without our server

The offline `check_claims` re-runs the contract code; it does not prove the testnet history. To check that history without the MCP testnet server:

1. Each `out/scenes/scene-N.json` (also `out/gates/*.json`, `out/agent-invests-testnet.json`, `out/llm-buyer-testnet.json`) lists its transactions in `txs[]`: `tx` (hash), `by` (signer), `receiver`, `method`, `ok`, `error` and `events` (the contract's event names). `txs[].explorer` is the NearBlocks link. Which world each scene ran on: [`docs/TESTNET.md`](TESTNET.md#scenes).
2. Read one from any archival node (signer = `by`):
   `curl -s https://archival-rpc.testnet.near.org -H 'content-type: application/json' -d '{"jsonrpc":"2.0","id":1,"method":"EXPERIMENTAL_tx_status","params":{"tx_hash":"<tx>","sender_account_id":"<by>","wait_until":"NONE"}}'`
   and compare `transaction.signer_id`, `receiver_id`, the method in `actions`, `status` and the `EVENT_JSON` logs.
3. With RPC, `make judge-testnet` does steps 1-2 for every recorded transaction plus live reads (K1-K9). With no RPC it exits 3 and marks each claim `unverified_network`: not checked, not failed.
